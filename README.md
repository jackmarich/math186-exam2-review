# MATH 186 · Exam 2 Review

Learn-then-prove practice for MATH 186 Exam 2: set algebra, counting, probability rules, conditional probability, independence, random variables, PMF/PDF/CDF, expected value and variance, and the Binomial / Bernoulli / Poisson / Uniform / Exponential / Normal families.

- **12 topic sections.** Each one has a lesson with a worked example, then Problem 1 (learn it) and Problems 2–3 (prove it). Problems 2 and 3 get new numbers on demand.
- **Practice exam.** A timed mock exam in the Test 1 format, auto-graded with full solutions.
- **"Which distribution?" drill.** Identify the family and its parameters, then compute a probability.
- **R console.** Real R running in the browser via webR.
- **Flashcards and a searchable formula sheet.**

Plain static HTML/CSS/JS with no build step. Open `index.html` through any static server.
